## 选题与内容

六篇围绕养猫人已经见过的行为、身体特征或尴尬场景。标题把读者的日常说法放进去，例如耳朵像「妙脆角」、开饭时上厕所产「巧克力」、眼前的东西找不到。一个题目只抓一个小疑问，正文可以围绕它延伸几个解释。

常见推进：日常场景 → 主人的疑惑或误解 → 猫的夸张反应 → 分段解释 → 对应行为或边界提醒 → 回到生活笑点。跟随内容灵活使用，不把每篇写成同样段数的模板。参考正文有些句式与用户禁用规则冲突，创作时按 writing-rules.md 执行。

图外文字负责信息，气泡负责对话；偶尔用箭头或简图解释身体结构。配角猫的毛色帮助呈现差异。拟人笑话与科学原因分开。原创声明、资料说明、读者猫照、推荐文章卡是文章末尾的其他模块；微信广告和按钮不应画进正文。

## 风格卡

| 项目 | 匹配结果 |
|---|---|
| 画法名称 | 白底粗黑线 Q 版宠物科普条漫，可带生活吐槽 |
| 线条 | 近黑、圆头、偏粗、粗细略变，轮廓有轻微不规则；线条清楚 |
| 人物 | 约 2 头身，大头、短圆四肢；猫可站立拿东西，也可四足趴卧 |
| 原账号角色识别 | 黑白猫、黑块额头与耳朵、白脸白胸、橘粉圆腮红、点线五官；主人同样大头短身。新稿使用已选的第 10 组角色 |
| 表情 | 嫌弃、疑惑、得意、崩溃，常用歪嘴、汗滴、短线眼、少量动作线 |
| 色彩 | 纯白占多数；黑色块、橘粉腮红、黄线为识别组合；道具少量灰蓝、浅绿、浅橙 |
| 文字 | 居中粗黑无衬线中文；字大清楚，按语义分为短行；无需强行手写字体 |
| 黄条 | 圆头黄色标记，位于某一行中下部；一组只标一句或一处重点 |
| 气泡 | 手画椭圆或圆角矩形，略不对称，黑边白底；尾巴指向说话角色 |
| 背景 | 多数白底无背景；一两件道具交代场景，少数单框场景作变化 |
| 图文关系 | 一组 2—4 行解释配一幅无框小漫画，偶尔只留表情或对白作停顿 |
| 留白 | 左右和单元之间都有空白，少装饰；不能做成密集的连续四格墙 |

## 避免画偏

水彩纸纹、细铅笔排线、精致毛发、写实猫、日漫大眼、3D 高光、复杂室内透视、满版装饰、长段小字，都会让这次的参考画法走样。不能用「hand drawn」几个字代替具体约束。

新稿采用已选独立角色，另写场景；线条、头身、表情、文字排版和少色平涂参考原图。评估时逐项看是否接近，不宣称像素级相同。
