# 公众号漫画文案规则

适用于选题标题、封面字、图内对白、说明文字、正文、导语及结尾。下面的词库是用户规则资料，允许在规则说明中原样记录；创作内容禁用。不要把对标文章中的说法自动带进新稿。

写作要求：口语化，短句为主，有具体判断，允许带个人偏见，不要面面俱到。每段交代一个具体动作、场景、事实或判断。对白要像人在现场说的话，说明文字补充图里看不到的信息。

## 人工审稿

- 结尾不升华，不用鸡汤收尾。
- 不喊口号，不拔高，不讲大道理。
- 不给每段加小标题，结构不要过于工整。
- 不写“什么都对但什么都没说”的圆滑结论。
- 谨慎使用词只有在上下文确实需要时才保留；可以换成具体事实的，就换掉。
- 硬性禁词与禁句有命中就改。不要为了通过扫描机械替换近义词，改成具体的人、动作、场景和可核对的信息。
- 检查图内文字和文章文字是否重复、是否有生硬转折、结论是否超出材料。科普事实另行核验，文案扫描不负责事实正确性。

## 机器扫描

执行 `python scripts/check_copy.py <UTF-8文本文件> [--json]`。从技能外调用时使用脚本的完整路径。扫描对象应包含待发布的标题、封面文字、对白、配文和正文，不要把本规则文件或分析记录混进成稿。

脚本从本页唯一的 JSON 围栏读取词库。硬性命中返回 1；只有谨慎词或没有命中返回 0；读取失败或规则格式错误返回 2。重叠命中会合并，保留关联规则。输出包含行号、列号、命中文字和附近片段。

这是确定性文案规则检查，不能测量“AI 概率”。未命中仅表示当前词库未发现问题，仍需人工检查口吻、具体程度、重复、套话、事实和画面配合。
