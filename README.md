# handraw-style · 公众号手绘漫画 Skill

把选题、写稿、分镜、正文漫画、封面和审稿连在一起，做带说明文字的中文公众号漫画。

## 能做什么

- 看参考文章，匹配线条、角色比例、配色、文字、气泡和留白。
- 选一个具体生活场景，写标题、摘要、旁白和对白。
- 按要求生成正文，例如六张正文、每张两个单元；头图、封面、人物介绍和番外另计。
- 准备无字主题封面，以及约2.35:1发布横封面；核对实际像素，尺寸未满足时注明预览及裁切要求。
- 固定开场：品牌头图 → 无字封面 → 人物对话介绍 → 正文。
- 固定结尾：互动提问 → 猫咪照片或漫画番外与配文 → END → 署名和转载联系。
- 核对资料、稿件、图片里的文字、角色一致性及手机排版，运行文案规则检查。

## 安装

下载仓库 ZIP 并解压，把包含 `SKILL.md` 的整个 `handraw-style` 文件夹放进 Codex 的个人 skills 目录：

- Windows：`%USERPROFILE%\.codex\skills\handraw-style`
- macOS / Linux：`~/.codex/skills/handraw-style`

安装后的目录应为 `skills/handraw-style/SKILL.md`，不要再多套一层同名文件夹。重新打开 Codex 后使用 `$handraw-style` 调用。

也可把本仓库地址交给支持 GitHub 安装的 skill 安装器。其他支持 `SKILL.md` 的代理环境请按对应环境的技能安装方式使用。

## 使用例子

```text
用 $handraw-style 拆解我提供的公众号文章。
先匹配画法，再用新的角色画两张带说明文字的样稿。
```

```text
用 $handraw-style 做一期《我就上个厕所，猫怎么也要跟？》。
正文六张，每张两个图文单元。封面无字，发布横封面2.35:1。
沿用角色，保留固定开场、互动、番外、END及署名。
先写稿核对资料，再出图、审稿和检查手机排版。
```

## 换成自己的账号和角色

内置案例使用账号 `AYU.阿屿`、人物陈屿和猫小屿，主角来自角色方案第10组；第1组仅在剧情需要时作配角。

使用自己的品牌时，在请求里指定账号名、人物名、宠物名及参考形象，再更新 `references/characters.md`、固定头图和介绍图。正文画面可以换，人物识别特征要保持一致。

## 文案规则检查

需要 Python 3，仅使用标准库：

```bash
python scripts/check_copy.py 你的稿件.txt --json
```

词库在 `references/writing-rules.md`。命中硬性规则时退出码为1，输入或规则读取失败为2。未命中只表示词库没有发现问题，不代表AI概率为零，仍需人工检查口吻、事实和画面。

图片生成需要运行环境提供图像生成工具。这个仓库不包含模型、API密钥或付费调用额度。

## 文件

- `SKILL.md`：入口与制作流程。
- `references/`：风格匹配、角色、文案及固定结尾。
- `scripts/check_copy.py`：文案规则扫描。
- `assets/`：角色方案、固定头图、介绍图及参考局部。

默认案例图片含AI辅助生成。原账号截图局部仅作为画法分析参考，相关标识和图像来自原作者；新稿使用独立角色。上传或群发文章需由使用者另行明确要求。
